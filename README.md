## 📓 100 Pandas Puzzles

**File:** `100-pandas-puzzles.ipynb`

A notebook of 100 short puzzles inspired by the [100 NumPy Exercises](https://github.com/rougier/numpy-100) project. Each puzzle targets a specific pandas concept, starting from the basics and gradually increasing in difficulty.

### Topics covered

| Section | Difficulty |
|---|---|
| Importing pandas & setup | Easy |
| DataFrame basics — selecting, sorting, adding, aggregating | Easy |
| DataFrames: beyond the basics — chaining methods | Medium |
| DataFrames: harder problems | Hard |
| Series and DatetimeIndex — working with time series data | Easy / Medium |
| Cleaning data — handling missing values, renaming, type casting | Easy / Medium |
| Using MultiIndexes — hierarchical indexing | Medium |
| Minesweeper — logic-based grid problem using pandas | Medium / Hard |
| Plotting — visualizing trends with pandas | Medium |

## 🚀 Getting Started

To run any notebook locally:

```bash
# Clone the repo
git clone  https://github.com/SumanGouda/PANDAS-MODULE
cd PANDAS

# Install dependencies
pip install pandas numpy matplotlib jupyter

# Launch Jupyter
jupyter notebook
```
